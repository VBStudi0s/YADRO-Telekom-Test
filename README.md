# Alice Game Bot

## Описание решения

Данное решение использует принцип разделения ответственности и dependency injection для достижения прозрачной и легко масштабируемой структуры.
Работа программы разделена на два этапа.
1) **Этап подготовки**: создание необходимых сущностей, парсинг входных данных, обработка ошибок
2) **Этап симуляции**: бот прогоняется в созданных условиях.

### Принцип работы бота

- Бот не выполняет преобразования игровых сущностей напрямую. напротив, он получает игровую обстановку, анализирует её и выносит решение - действие (`Action`).
- Действия инкапсулируют в себе необходимые преобразования над игровым миром и производят их по вызову основного контроллера симуляции `GameManager`.

### Архитектура решения

- Бот и действия реализуют соответствующие интерфейсы, что делает код расширяемым, а добавление новых ботов простым.
- Отдельная от логики бота система логирования же позволяет добавлять новых ботов, не затрагивая систему анализа их действий.

## Сборка и запуск

Код не требует дополнительных библиотек и зависимостей, кроме CMake.

Для сборки пропишите
```
make build
```

или

```
mkdir -p build && cd build && cmake .. && make
```

Для запуска используйте
```
make run
```
предварительно настроив входной файл, или

```
./build/alice_bot <входной файл>
```
